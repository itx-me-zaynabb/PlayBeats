# 🎵 PlayBeats

PlayBeats is a simple and stylish music player web app built using **HTML, CSS, and a little animation**.  
It’s inspired by Spotify, but designed with a clean and minimal UI.

---

## 🧠 Features
- Beautiful and responsive design  
- Animated header section  
- Albums and Home page only (no backend)  
- Custom PlayBeats logo instead of Spotify  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
-  JavaScript for minor animations
